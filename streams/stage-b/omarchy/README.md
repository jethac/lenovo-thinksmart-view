# Omarchy (dropped)

Preparation for installing Omarchy on this tablet: a trimmed package set (`tablet.packages`, `tablet.add`, `tablet.drop`), a patch to `omarchy-arm`, touch-friendly settings and `install-omarchy.sh`. Omarchy was dropped on 2026-10-30 (`GOAL.md`): the tablet is a single-purpose voice appliance and 2 GB of RAM goes to the speech models. Kept as a record only.
